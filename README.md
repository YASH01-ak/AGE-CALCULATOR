# 🧮 AGE CALCULATOR

> **A simple and user-friendly age calculator website to calculate age quickly and accurately.**

🌐 **Live Website:** `https://yash01-ak.github.io/AGE-CALCULATOR/`

---

## ✨ About Age Calculator

**Age Calculator** is a simple web-based tool designed to calculate a person's age based on their date of birth.

The website provides an easy-to-use interface where users can select their **day, month, and year of birth** and calculate their age instantly.

### 🎯 Main Goals

* 🧮 Calculate age quickly
* 📅 Make date selection simple
* 📊 Show accurate age information
* 💻 Provide a clean and easy-to-use interface
* 📱 Keep the website simple and responsive

---

## 🚀 Features

* 📅 Separate day, month, and year selection
* 🧮 Automatic age calculation
* 🎂 Displays calculated age
* 📱 Responsive design
* 🎨 Clean and modern interface
* ⚡ Lightweight and fast

## 🧮 How It Works

1. Select your **day of birth**.
2. Select your **month of birth**.
3. Select your **year of birth**.
4. Click the **Calculate Age** button.
5. The website calculates and displays your current age.

The calculation is performed directly in the browser using JavaScript.

---

## 🔐 Privacy

This website is designed as a client-side project.

* No account is required.
* No personal information is collected by the calculator itself.
* The entered date of birth is processed in the browser.
* No external database is required for the calculation.
